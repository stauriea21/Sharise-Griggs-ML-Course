## Presentation Topics Covered

- Introduction to the IoT Temperature Forecasting dataset (97,606 readings)
- Data preparation and preprocessing steps

- Feature engineering: lag values, rolling averages, hour, day of week
- Generative modeling: synthetic data augmentation and its impact on performance
- Key insights and recommendations for IIoT forecasting systems

---

## Key Recommendations Presented

- Use time-based feature engineering such as lag and rolling mean to capture sensor behavior patterns
- Apply synthetic data augmentation when rare IIoT conditions are underrepresented in training data
- Always use chronological train-test splits — never random splits for time-series data
