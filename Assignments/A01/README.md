## Problem Statement

This assignment explored the key development tools used in Edge AI and IoT projects — understanding what they are, why they matter, and how they are used in real-world systems.

---

## Tools Covered

| Tool | Purpose |
|------|---------|
| Visual Studio Code | Primary IDE for writing and debugging AI/IoT code |
| Node.js | Server-side scripting and real-time device communication |
| Edge Impulse CLI | Building and deploying ML models on edge hardware |
| TensorFlow and TensorFlow Lite | Training models and deploying them to edge devices |
| Google Colab | Cloud-based development and model testing |
| GitHub Copilot and OpenAI Codex | AI-assisted coding and debugging |

---

## My Approach

I researched each tool individually and wrote a structured report explaining its description, purpose, and typical use cases. I included illustrative examples for each tool using a healthcare IoT scenario to show how these tools work together in real-world edge AI deployments.

---

## Key Takeaways

- Edge AI tools work best as a connected ecosystem, not in isolation
- TensorFlow Lite bridges the gap between powerful model training and lightweight edge deployment
- Tools like Google Colab lower the barrier to entry for AI development without expensive hardware
